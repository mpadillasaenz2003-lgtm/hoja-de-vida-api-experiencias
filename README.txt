HOJA DE VIDA - UNIDAD 2
Tecnologías incorporadas:
- Bootstrap 5.3.3 mediante CDN para diseño responsive, navbar, cards, botones y formulario.
- jQuery 3.7.1 para animaciones de entrada y efectos del formulario.
- JavaScript para validar nombre, correo, asunto, mensaje y aceptación de términos.
- Se corrigió la etiqueta de imagen de index.html y se mantuvo la información de la Unidad 1.
- API CRUD de experiencias profesionales con Express.js y MongoDB: ver api-experiencias/README.md para la instalación, los endpoints y la documentación Swagger.

Para ejecutar: descomprimir y abrir index.html en un navegador con conexión a Internet para cargar Bootstrap/jQuery desde CDN.
